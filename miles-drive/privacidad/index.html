Política de privacidad de miles-drive

Última actualización: 17 de octubre de 2026.

Esta política explica cómo miles-drive (en adelante, «la aplicación») trata los datos de sus usuarios. La aplicación es una herramienta personal de gestión de archivos, de uso privado, y no se ofrece al público.

1. Responsable

El responsable del tratamiento es el titular de la aplicación. Su correo está en el apartado Contacto.

2. Datos que se tratan

  • Archivos y sus datos descriptivos, como el nombre, el tipo o la ubicación, guardados en los servicios de almacenamiento en la nube de terceros a los que el usuario concede acceso.
  • Credenciales de autorización que emite el proveedor cuando el usuario concede el permiso. La aplicación no conoce ni guarda la contraseña del usuario.

La aplicación no recoge datos de pago, ubicación, contactos ni categorías especiales de datos.

3. Finalidad

Los datos se tratan exclusivamente para prestar las funciones que el usuario solicita en cada momento, es decir, gestionar sus propios archivos.

4. Uso limitado de los datos

  • Los datos a los que se accede con el permiso del usuario solo se usan para prestar o mejorar las funciones que el propio usuario utiliza.
  • No se usan para publicidad ni para elaborar perfiles.
  • No se usan para desarrollar, mejorar ni entrenar modelos generales de inteligencia artificial o de aprendizaje automático.
  • Nadie lee el contenido de los archivos, salvo que el usuario lo pida, que sea necesario por motivos de seguridad o que lo exija la ley.
  • Los datos solo se transfieren en los casos del apartado 5.

5. Comunicación de datos

Los datos no se venden, alquilan ni ceden a terceros. Solo se comunican en estos casos:

  • Cuando el usuario lo pide expresamente, por ejemplo, al compartir un archivo concreto con una persona.
  • A proveedores de servicios técnicos que actúan por cuenta del responsable, solo en la medida necesaria para prestar la función solicitada y con obligación de confidencialidad.
  • Cuando lo exija la ley.

6. Conservación

Los archivos permanecen en el servicio de almacenamiento del usuario. La aplicación no conserva copias permanentes. Las copias temporales que se generen para cumplir una tarea se eliminan al terminarla. Las credenciales de autorización se conservan mientras el permiso esté vigente y se eliminan cuando se retira.

7. Seguridad

Se aplican medidas técnicas y organizativas razonables para proteger los datos frente a accesos no autorizados, pérdida o alteración.

8. Tus derechos y cómo borrar tus datos

  • Retirar el permiso: en cualquier momento, desde la configuración de seguridad de tu cuenta en el proveedor de almacenamiento, en el apartado de aplicaciones con acceso a la cuenta. Desde ese momento la aplicación deja de tener acceso.
  • Acceso, rectificación y supresión: para pedir información sobre tus datos o que se borren, escribe al correo del apartado Contacto. La solicitud se atenderá en el plazo de un mes.

9. Cambios en esta política

Si esta política cambia, la nueva versión se publicará en esta página con su fecha de actualización.

10. Contacto

Para cualquier duda sobre privacidad o para pedir el borrado de tus datos, escribe al correo de contacto del titular.
