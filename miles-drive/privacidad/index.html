Política de privacidad de miles-drive

Última actualización: 17 de octubre de 2026.

Esta política explica cómo miles-drive (en adelante, «la aplicación») trata los datos de sus usuarios. La aplicación es una herramienta personal de productividad de uso privado y no se ofrece al público.

1. Responsable

El responsable del tratamiento es el titular de la aplicación. Puedes contactar con él en familydr.lab@gmail.com.

2. Datos que se tratan

  • Archivos y sus metadatos (nombre, ubicación, tipo y permisos) almacenados en los servicios de Google del usuario, como Google Drive, a los que el usuario concede acceso a través de la pantalla de permisos de Google.
  • Credenciales de autorización emitidas por Google al conceder el permiso. La aplicación no conoce ni guarda la contraseña del usuario.

La aplicación no recoge datos de pago, ubicación, contactos ni categorías especiales de datos.

3. Finalidad

Los datos se tratan exclusivamente para prestar las funciones que el usuario solicita en cada momento, es decir, organizar y gestionar sus propios archivos. No se usan para publicidad ni para elaborar perfiles, ni para ninguna otra finalidad.

4. Uso limitado de los datos de Google

El uso que hace la aplicación de la información recibida de las API de Google, y su transferencia a cualquier otra aplicación, se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Los datos obtenidos de las API de Google no se usan para desarrollar, mejorar ni entrenar modelos generalizados de inteligencia artificial o aprendizaje automático.

5. Comunicación de datos

Los datos no se venden, alquilan ni ceden a terceros. Solo se comunican en estos casos:

  • Cuando el usuario lo pide expresamente, por ejemplo, al compartir un archivo concreto con una persona.
  • A proveedores de servicios técnicos que actúan por cuenta del responsable, solo en la medida necesaria para prestar la función solicitada y con obligación de confidencialidad.
  • Cuando lo exija la ley.

6. Conservación

Los archivos permanecen en los servicios de Google del usuario. La aplicación no conserva copias permanentes. Las copias temporales que se generen para cumplir una tarea se eliminan al terminarla. Las credenciales de autorización se conservan mientras el permiso esté vigente y se eliminan cuando se retira.

7. Seguridad

Se aplican medidas técnicas y organizativas razonables para proteger los datos frente a accesos no autorizados, pérdida o alteración.

8. Tus derechos y cómo borrar tus datos

  • Retirar el permiso: en cualquier momento, desde los permisos de tu cuenta de Google. Desde ese momento la aplicación deja de tener acceso.
  • Acceso, rectificación y supresión: para pedir información sobre tus datos o que se borren, escribe a familydr.lab@gmail.com. La solicitud se atenderá en el plazo de un mes.

9. Cambios en esta política

Si esta política cambia, la nueva versión se publicará en esta página con su fecha de actualización.

10. Contacto

Para cualquier duda sobre privacidad, escribe a familydr.lab@gmail.com.
