# Portada del laboratorio

Web pública en <https://josebadg.github.io/>, servida con GitHub Pages desde `main` (raíz).

## Páginas

| Página | URL |
| --- | --- |
| Portada del laboratorio | https://josebadg.github.io/ |
| miles-drive: página principal | https://josebadg.github.io/miles-drive/ |
| miles-drive: política de privacidad | https://josebadg.github.io/miles-drive/privacidad/ |
| miles-drive: condiciones del servicio | https://josebadg.github.io/miles-drive/condiciones/ |

Las tres páginas de miles-drive son las que pide Google en «Información de la marca» para publicar la pantalla de permisos OAuth. El dominio autorizado es `josebadg.github.io`. Si cambian las URL, hay que cambiarlas también en la consola de Google; si no, la app deja de cumplir los requisitos.

## Normas

- HTML y CSS sin dependencias ni scripts. Castellano, responsive y accesible (WCAG 2.2 AA).
- Sin nombres ni datos personales. El único dato de contacto es el correo del laboratorio.
- `.nojekyll` evita que Pages procese el sitio con Jekyll.
